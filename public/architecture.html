System map

Express serves the browser UI, dispatches JSON API requests under /api, and returns printable invoice HTML from a separate route.

  1. Browser

    public/index.html and public/js/app.js display the register, order history, inventory, and Khata balances.

  2. Express routes

    server.js serves public/ and connects the product, order, customer, and report routes.

  3. Business rules

    lib/ handles pricing, coupons, GST, inventory, orders, dates, Khata, invoices, and reports.

Request handlers↔lib/store.js ↔ data/db.json

config.js supplies coupon rules, GST slabs, and shop settings. The JSON file holds the shop's products, orders, customers, settlements, and audit log.

Checkout

POST /api/orders records an order after stock, coupon, and any applicable Khata credit checks succeed.

  1. Resolve items

    Read the store and resolve the submitted product IDs and quantities.

  2. Check stock

    Check the combined quantity per product against physical stock minus wholesale holds.

  3. Price the order

    Validate the coupon, distribute its discount, and apply the GST slab to each discounted line.

  4. Apply changes

    Check the Khata credit limit and record the charge when applicable, then deduct physical stock.

  5. Save the sale

    Save the order totals and audit entry in the JSON file and return 201 Created.

Other workflows

Invoice and GST audit

GET /orders/:id/invoice
GET /api/reports/gst-reconciliation

Both use lib/invoice.js. The invoice uses recorded totals and checkout's calculation for line GST. The reconciliation report compares the invoice summary with the ledger.

Cancel an order

POST /api/orders/:id/cancel

lib/orders.js checks the current status, returns physical stock, and reverses a Khata charge where applicable. Wholesale holds are preserved.

Order history

GET /api/orders

lib/dates.js converts saved dates and filter values into sortable keys. lib/orders.js applies the inclusive bounds and sorts newest first.

Khata settlement

POST /api/customers/:id/settle

lib/ledger.js validates the payment and updates the balance in whole paise. The customer route records the settlement and audit entry.
